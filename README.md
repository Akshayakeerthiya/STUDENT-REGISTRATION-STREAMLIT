# STREAMLIT LEARNING

## About

This repository contains my **hands-on learning and practice with Streamlit using Python**.

As part of learning Streamlit, I explored different UI components, user input elements, layouts, and interactive features by building a small **Student Registration Web App**.

## What I Practiced

* Text and number inputs
* Text area
* Selectbox and radio buttons
* Multiselect
* Date input
* Checkbox and button
* Sidebar
* Columns
* Container
* Expander
* Displaying user-entered data

## Technologies Used

* Python
* Streamlit

## Run Locally

Install Streamlit:

```bash
pip install streamlit
```

Run the application:

```bash
streamlit run app.py
```
